# 最後的皇朝：康雍乾盛世

課堂用的 3D 探索遊戲（小六常識）。玩家以年輕宮廷侍從／學生探險者的身分，走訪康熙庭院、雍正大殿與乾隆戶外場景，傾談、調查、作答，了解清朝早期盛世及其轉變。

本作品是**原創課堂遊戲**，場景為紫禁城風格的想像宫廷，並非故宮／紫禁城官方產品，亦不是真實宮殿的掃描或複製，更不是任何出版社教科書或電子書頁面的再現。

## 本機運行

需要已安裝的 Node.js（建議 20 或以上）。

```bash
cd qing-shengshi-3d
npm install
npm run dev
```

然後用瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:5173/`）。

- 課室 iPad：用觸控虛擬搖桿移動，拖曳畫面轉動視角，點大按鈕「傾談／調查」。
- 桌上電腦：`W A S D` 或方向鍵移動，拖曳滑鼠轉動視角，`E` 或空白鍵互動。

正式建置：

```bash
npm run build
npm run preview
```

建置結果在 `dist/`。本專案已設定 Vite `base: './'`，之後可用 GitHub Pages 以專案頁形式發佈（相對路徑）。倉庫內已預備 `.github/workflows/pages.yml` 與 `public/.nojekyll`，開倉後再啟用即可。

## 操作與關卡

開場問題：清朝早期為甚麼會出現盛世？後來有甚麼轉變？

1. **康熙（宮殿庭院）** — 與康熙皇帝、滿族人、漢族人傾談，收集證據後，出口會解鎖三題選擇題。全對後輸入密碼 `123` 進入下一關。
2. **雍正（大殿）** — 與雍正皇帝、貪官及國庫線索調查後作答，密碼 `456`。
3. **乾隆（戶外：陸地 + 海邊）** — 走訪準噶爾平亂、和珅、農田與南巡船隊，作答後輸入密碼 `789`，然後登上大船，觀看短短的開船與本課小結。

畫面上有「康雍乾盛世」國勢條：康熙、雍正時期強盛，乾隆前期（準噶爾）達到高峰，走到乾隆晚年區域會轉弱。
